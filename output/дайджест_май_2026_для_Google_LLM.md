## 3. Проекты по страховым компаниям

### 3.1. РГС

#### VFOS РГС — разработка
- **PM:** Сорванов О.Н.
- **Команда:** 4 разработчика, 2 аналитика, 1 тестировщик
- **Модель:** T&M, Agile Scrum, спринты 2 недели
- **Результат с 01.01.2026:** 61 крупная задача выполнена, 21 в работе

**Ключевые достижения:**
1. **Госуслуги.Дом** — запуск продаж КСП ИФЛ; потенциал до 60 млн ₽/год. Сервис интеграции на .NET 10: асинхронная очередь, OAuth2/Keycloak, мониторинг, OpenAPI/NSwag, mock-контур.
2. **Кросс-продажи мигрантам** — «Добро пожаловать в гости» (152 правила) через API для ФГУП ПВС МВД к «РГС Гость_2016» (220 правил); потенциал 100 млн ₽/год.
3. **Автовыгрузка в учётную систему** — НС, ИФЛ, ДМС в ЕКИС без ручной загрузки XML.
4. **Регуляторика ЦБ** — передача данных личного страхования в НСИС (ЭФ, API, загрузчики).
5. **Keycloak** — полный переход на новую авторизацию (Волосников А.).
6. **Инфраструктура** — развёрнут 3-й интеграционный контур.

**Ключевые сотрудники:** Рыжикова Ю., Рудченко П., Сивогривова Н., Нижурин С., Агалетдинов А., Кукарин Д., Волосников А.

**ОФР.ИФЛ — внедрено:**

## 9. Инструкция для Google LLM

При ответах на вопросы по этому дайджесту:
1. Указывай **страховую компанию** и **PM** при описании проекта.
2. Разделяй **разработку** и **техподдержку**.
3. Для финансовых показателей уточняй: «потенциал» vs «факт».
4. Статистика ТП — накопительная с **01.01.2026**, если не указано иное.
5. Проект Virtu Drive — **бессрочная пауза**, не считать активным.
6. Цифры 60/100 млн ₽ — **план на 1-й год** после точки внедрения, не многолетний прогноз.
7. **Разработка** и **техподдержка** — разные активности, не суммировать в одном графике.
